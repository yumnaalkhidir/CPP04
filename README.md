# CPP04

42 School C++ Module 04 — subtype polymorphism, abstract classes, and interfaces.

## Concepts covered
- Subtype polymorphism and virtual destructors
- Abstract classes and pure virtual functions
- An Animal/WrongAnimal hierarchy plus a deep-copying Brain class

## Exercises
ex00 ex01 ex02 

## Build & run
Each exercise has its own Makefile:
```sh
cd exXX
make
./<binary_name>
```
